# Welcher dieser Berge ist der höchste?

Alle vier Berge sind Nicht-Himalaya-Gipfel. Elbrus (Russland/Kaukasus) gilt je nach Definition als höchster Berg Europas – Mont Blanc als Alternative. Das Matterhorn ist berühmt für seine markante Form. Der Kilimandscharo ist ein Stratovulkan in Tansania.
