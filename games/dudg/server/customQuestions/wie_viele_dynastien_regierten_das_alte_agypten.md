# Wie viele Dynastien regierten das alte Ägypten?

Das alte Ägypten wurde über 3.000 Jahre lang von 31 Dynastien regiert. Die erste begann
um 3100 vor Christus mit Konig Menes. Die letzte endete, als Alexander der Große das
Land eroberte. Kein anderes Reich der Welt hielt so lange zusammen. (Eine Dynastie ist ein Familienstammbaum an der Macht)
